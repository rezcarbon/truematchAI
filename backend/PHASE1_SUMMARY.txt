📞 TROUBLESHOOTING QUICK REFERENCE
─────────────────────────────────────────────────────────────────────────────

Issue: "Assessment outcome endpoint returns 403"
  → Check: User role is recruiter? (candidates cannot record)
  → Check: Recruiter has access to position's company?

Issue: "Nightly learning task not running"
  → Check: Celery beat running? (celery -A app.workers beat)
  → Check: Is task registered? (celery -A app.workers inspect active_queues)
  → Check: Task scheduled? (beat_schedule in celery_app.conf)

Issue: "Metrics show null values for accuracy"
  → Check: Are there outcomes recorded? (SELECT COUNT(*) FROM hiring_outcomes)
  → Check: Do assessments have capability_score? (SELECT COUNT(*) FROM assessments WHERE capability_score IS NOT NULL)
  → This is normal on first day - wait until nightly task runs with data

Issue: "Database migration fails"
  → Check: PostgreSQL version >= 11? (JSONB required)
  → Check: User has CREATE TABLE permissions?
  → Rollback: alembic downgrade 0043
